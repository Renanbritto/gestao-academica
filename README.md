# 🎓 AcademiaGlow — Aplicação Web de Gestão Acadêmica

Aplicação web estática (HTML5 / CSS3 / JavaScript Vanilla), ultra rápida, responsiva e com persistência de dados local (**LocalStorage**).

Feito com um visual impecável em **Glassmorphism**, suporte a **Modo Claro / Escuro** e com uma mensagem especial de incentivo para ela!

---

## 🌟 Recursos

1. **Deploy Gratuito com 1 Clique (GitHub Pages / Netlify / Vercel)**.
2. **Sem necessidade de servidor / backend**: Todos os dados (matérias, provas, notas, mensagem e tema) são salvos de forma segura no `localStorage` do próprio navegador dela.
3. **Métricas Inteligentes**:
   - Média Geral (CR) calculada automaticamente.
   - Rendimento por matéria com barras visuais.
   - **Calculadora de Meta**: *"Quanto preciso tirar na próxima prova?"*.
   - **Central de Avisos**: Contagem regressiva de dias com alertas coloridos por urgência (🔴 Urgente < 3d, 🟡 Atenção < 7d, 🟢 Ok > 7d).

---

## 💻 Como Rodar Localmente

Basta dar um duplo clique no arquivo **`index.html`** na pasta `C:\mona` ou abrir pelo navegador!

---

## ☁️ Guia de Deploy Gratuito no GitHub Pages (Passo a Passo)

O GitHub hospeda este tipo de site de graça para sempre em menos de 2 minutos:

1. Acesse o seu [GitHub](https://github.com) e crie um novo repositório chamado `gestao-academica` (público).
2. Faça o upload dos 3 arquivos principais (`index.html`, `style.css`, `app.js`) para o repositório.
3. No repositório, clique na aba **Settings** (Configurações).
4. No menu lateral esquerdo, clique em **Pages**.
5. Em **Build and deployment > Source**, selecione `Deploy from a branch`.
6. Escolha o branch `main` e a pasta `/ (root)`. Clique em **Save**.
7. Pronto! Em 1 minuto o GitHub vai te fornecer o link público (ex: `https://seu-usuario.github.io/gestao-academica`).
